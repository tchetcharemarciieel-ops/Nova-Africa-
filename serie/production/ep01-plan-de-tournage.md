## Chaîne de production conseillée
1. **Images clés** : générer chaque personnage (Midjourney / Flux) pour garder le même visage.
2. **Vidéo** : image → vidéo dans Runway, Kling ou Veo avec les prompts ci-dessus.
3. **Voix** : ElevenLabs pour les dialogues (scénario dans `serie/episodes/ep01-la-veille.md`).
4. **Musique** : Suno, ambiance électro-afro sombre.
5. **Montage** : CapCut ou DaVinci Resolve (≈ 1 min 10 de plans, à allonger avec les dialogues).
